# 游戏规则

> 本文件记录地图生成系统各层的**设计规则**与**模块职责说明**，是理解生成逻辑的核心参考。

---

## 第一层：地形与气候层（`TerrainLayerGen`）

### 模块职责

| 模块 | 文件 | 职责 |
| :--- | :--- | :--- |
| Facade 主入口 | `TerrainLayerGen.cs` | 统一调度气候→地形→保护→城邦 |
| 气候噪声 | `ClimateGenerator.cs` | 生成 200×200 的 `ClimateData` 矩阵（包含 `Altitude`, `Humidity`, `Temperature` 以及河流侵蚀） |
| 地形决策树 | `TerrainEvaluator.cs` | 逐格根据 `ClimateData` 和 `dangerBias` 映射为 `TerrainType` 枚举值 |
| 大本营保护 | `BaseCampProtector.cs` | 强制将地图中心以 `PROTECTION_RADIUS = 5` 为半径的切比雪夫矩形区域内的地形设为 `PLAINS` |
| 城邦放置 | `CityStateGenerator.cs` | 在外圈随机放置 3 个 `CITY_STATE` 地形标记，以供后续层生成使用 |

### 地形生成规则

1. **水域**：最终融合高度 `finalAltitude < WATER_THRESHOLD (0.18f)` → `WATER`
2. **山地**：最终融合高度 `finalAltitude > MOUNTAIN_THRESHOLD (0.60f)` → `MOUNTAIN`
3. **沼泽**：湿度 `Humidity > SWAMP_HUMIDITY_MIN (0.65f)` 且温度 `Temperature < SWAMP_TEMP_MAX (0.45f)` → `SWAMP`
4. **安全区（圈层 `ringDistance <= SAFE_ZONE_RADIUS (10)`）**：强制为 `PLAINS`
5. **过渡区（`10 < ringDistance <= TRANSITION_ZONE_RADIUS (25)`）**：正常评估，但危险偏置 `dangerBias` 极低
6. **危险区（`25 < ringDistance <= DANGER_ZONE_RADIUS (50)`）**：危险偏置 `dangerBias` 中等
7. **极端区（`ringDistance > EXTREME_RING_MIN (70)`）**：温度 `Temperature > VOLCANO_TEMP_MIN (0.75f)` → `VOLCANO`；温度 `Temperature < TUNDRA_TEMP_MAX (0.25f)` → `TUNDRA`
8. **大本营保护**：地图中心周围 `PROTECTION_RADIUS = 5` 半径内强制重写为 `PLAINS`，随后在中心点放置 `BASE_CAMP` 标记。此规则优先级最高，最后覆盖执行。
9. **城邦约束**：与地图中心切比雪夫距离严格 `> MIN_DIST_FROM_CENTER (60f)`，且城邦两两间距 `> MIN_DIST_BETWEEN (40f)`。

## 第二层：资源分布层（`ResourceLayerGen`）

### 模块职责

| 模块 | 文件 | 职责 |
| :--- | :--- | :--- |
| Facade 主入口 | `ResourceLayerGen.cs` | 按序调度森林→矿石→草药生成，执行局部安全实例化 |
| 森林分布 | `ForestGenerator.cs` | 噪声驱动森林覆盖，并在大本营附近执行减密处理 |
| 矿石分布 | `MineralGenerator.cs` | 根据圈层区间，决定生成石矿、铁矿或水晶矿，且离中心越远生成概率越高 |
| 草药分布 | `HerbsGenerator.cs` | 仅在沼泽与平原地表随机散布，不得与矿石重叠 |

### 资源生成规则

1. **森林**：噪声值 `> FOREST_THRESHOLD (0.55f)` 且地形非水、山、火山、冻原 → 设 `HasForest = true`，并依据噪声值确定 `ForestDensity`；在大本营附近 `FADE_RADIUS = 12` 范围内阈值乘上 `1/0.6f`（减密）。
2. **矿石分区**：
   * 圈层 `ringDistance <= STONE_ZONE_MAX (20)`：仅生成石矿 `"STONE"`。
   * 圈层 `20 < ringDistance <= IRON_ZONE_MAX (45)`：生成铁矿 `"IRON"`。
   * 圈层 `ringDistance > 45`：生成稀有水晶矿 `"CRYSTAL"`。
   * 距离越远，判定阈值衰减越低（越容易出矿）：`BASE_THRESHOLD - (ringDistance/MAP_SIZE) * DISTANCE_FACTOR`。
   * 满足条件则设 `HasMineralVein = true` 并填入 `MineralType`。
3. **草药**：在沼泽与平原地表随机散布。若该格已有 `HasMineralVein == true`，则跳过不叠加。通过判定则设 `HasHerbs = true`。
4. **兜底初始化规则**：若 `store.ResourceLayer == null`，单独执行资源层矩阵初始化，**严禁调用 `InitArrays()`**，以防清空第一层地形数据。

## 第三层：建筑分布层（`BuildingLayerGen`）

### 模块职责

| 模块 | 文件 | 职责 |
| :--- | :--- | :--- |
| Facade 主入口 | `BuildingLayerGen.cs` | 按序调度基地与城邦写入、世界遗迹与极客奇观生成 |
| 基地与城邦放置 | `CampStatePlacer.cs` | 遍历第一层地形图，将 `BASE_CAMP` 和 `CITY_STATE` 地形转化为对应的建筑数据写入 `BuildingLayer` |
| 遗迹与奇观生成 | `RuinsGenerator.cs` | 生成 5~8 个世界遗迹和 2~4 个不可重复的远古极客奇观 |

### 建筑生成规则

1. **大本营**：固定放置于地图中心 `(CENTER, CENTER)`，`BuildingType = "BASE_CAMP"`, `HasBuilding = true`, `BuildingLevel = 1`, `IsWorldGenerated = true`。
2. **城邦**：读取第一层 `CITY_STATE` 地形标记格，写入对应位置：`BuildingType = "CITY_STATE"`, `HasBuilding = true`, `BuildingLevel = 1`, `IsWorldGenerated = true`。
3. **世界遗迹**：数量 5~8 个，从 `RUINS_IDS` 池中随机抽取 ID，可在任何可通过的非水陆地上重复放置。
4. **远古奇观**：
   * 数量 2~4 个，切比雪夫圈层必须外于 `WONDER_RING_MIN (50)`，两两间距 `> MIN_WONDER_DIST (20)`。
   * ID 从 `WONDER_IDS` 中通过 Fisher-Yates 算法**不重复**抽取。
   * 地形限制放宽为：只要非水域、非火山即可。
   * 避让资源格：奇观格子不能存在已生成的森林、矿脉或草药（即 `HasForest`, `HasMineralVein`, `HasHerbs` 均为 `false`）。
5. **兜底初始化规则**：若 `store.BuildingLayer == null`，单独初始化 `BuildingLayer` 矩阵，**严禁调用 `InitArrays()`**。

## 第四层：迷雾与怪物层（`MonsterFogLayerGen`）

### 模块职责

| 模块 | 文件 | 职责 |
| :--- | :--- | :--- |
| Facade 主入口 | `MonsterFogLayerGen.cs` | 按序调度全图黑雾与大本营开雾、怪物刷新及建筑联动 |
| 迷雾覆盖 | `FogGenerator.cs` | 初始全图所有格子均处于未探索迷雾中，仅大本营周边 5 格可见 |
| 怪物生成 | `MonsterGenerator.cs` | 利用动态噪声和地形权重刷怪，并将处于存活怪物的格子联动冻结其上的建筑功能 |

### 迷雾与怪物生成规则

1. **初始迷雾**：全图所有格子 `IsExplored = false`（黑雾笼罩）。
2. **大本营开雾**：与大本营中心切比雪夫距离 `ringDistance <= PROTECTION_RADIUS (5)` 的格子，强制标记 `IsExplored = true`，确保玩家出生点视野开阔。
3. **怪物刷新**：
   * 基础阈值：怪物噪声 `> BASE_DANGER_THRESHOLD (0.65f)`。
   * 圈层动态衰减：越往外圈刷怪率越高，动态阈值公式为 `BASE_DANGER_THRESHOLD - (ringDistance/MAP_SIZE) * DANGER_FACTOR (0.05f)`。
   * 地形额外刷怪几率（二次掷骰）：若噪声过线，山地有 `CHANCE_MOUNTAIN (0.12f)` 概率刷怪；沼泽有 `CHANCE_SWAMP (0.15f)` 概率刷怪；其他陆地地形有 `CHANCE_OTHER (0.06f)` 概率刷怪；水域及火山完全不刷怪。
   * 怪物类型分档：
     * `ringDistance <= 30`：怪物类型为 `"SLIME"`。
     * `30 < ringDistance <= 55`：怪物类型为 `"GOBLIN"`。
     * `55 < ringDistance <= 80`：怪物类型为 `"ORC"`。
     * `ringDistance > 80`：怪物类型为 `"DRAGON"`。
   * 刷怪格设 `HasMonster = true` 且 `MonsterType` 填入相应 ID。
4. **建筑冻结联动**：若当前格子已被世界建筑或玩家建筑占据（即 `BuildingLayer[x, y].HasBuilding == true`），此格不得刷新怪物，并在 `MonsterFogLayer` 中设 `IsBuildingBlocked = true`。若无建筑则为 `false`。
5. **怪物存活联动（运行时效果描述）**：如果格内有存活怪物（`HasMonster == true`）且该格拥有建筑，会使建筑图层中的对应建筑 `BuildingLayer[x, y].IsBuildingBlocked = true`（失效冻结）。
6. **兜底初始化规则**：若 `store.MonsterFogLayer == null`，单独初始化 `MonsterFogLayer` 矩阵，**严禁调用 `InitArrays()`**。
