# 变量速查表

> 本文件汇总所有层的**关键变量名**、**结构体字段**与**常量值**，以及它们在系统中的**具体作用与功能影响**，供开发时快速对照，避免命名歧义。

---

## 1. 核心单例与层级数组：`MapDataStore`

| 变量名 / 属性名 | 类型 | 作用与功能影响 |
| :--- | :--- | :--- |
| `MAP_SIZE` | `const int` | **地图边长（固定 200）**：限制所有坐标遍历 `[0, 199]`，是计算切比雪夫距离的基础。 |
| `CENTER` | `const int` | **地图中心坐标（固定 100）**：大本营固定生成点，亦是所有圈层距离（切比雪夫距离）的计算起点。 |
| `TerrainLayer` | `TerrainType[,]` | **第一层：地形层**：存储全局各格的地形类型（如 `PLAINS`, `MOUNTAIN`, `WATER` 等），决定了第二层资源和第三层建筑的生成合法性判定。 |
| `RawClimateLayer` | `ClimateData[,]` | **原始气候层**：存储全局各格的高度、湿度、温度数据，作为第一层地形决策树的输入源，后续层也可以作为参考。 |
| `ResourceLayer` | `ResourceData[,]` | **第二层：资源分布层**：存储全局各格的森林、矿脉、草药等自然资源信息，必须依赖地形层的数据来决定放置合法性。 |
| `BuildingLayer` | `BuildingData[,]` | **第三层：建筑分布层**：存储玩家大本营、中立城邦、世界遗迹及远古奇观。建筑会占据格子，并与第四层的怪物刷新产生“冻结”联动。 |
| `MonsterFogLayer` | `MonsterFogData[,]` | **第四层：迷雾与怪物层**：存储迷雾探索状态、危险区等级、存活怪物状态及怪物类型。有建筑的格子会被标记为阻挡，不刷新怪物。 |

## 2. 核心结构体字段及其作用

### 2.1 气候数据：`ClimateData`

| 字段名 | 类型 | 作用与功能影响 |
| :--- | :--- | :--- |
| `Altitude` | `float` | **高度值 (0.0~1.0)**：高度决定陆地与海洋。`< 0.18` 判定为水域；`> 0.60` 判定为山地；介于中间时，作为其他地形的评估基准。 |
| `Humidity` | `float` | **湿度值 (0.0~1.0)**：湿度和温度共同决定气候地形。湿度 `> 0.65` 时可产生沼泽。在极端外圈，低湿度结合低温度则生成冻土。 |
| `Temperature` | `float` | **温度值 (0.0~1.0)**：`0`代表极寒，`1`代表极热。低温度结合高湿度生成沼泽；极远圈层的高温度生成火山，低温度生成冻土。 |

### 2.2 资源数据：`ResourceData`

| 字段名 | 类型 | 作用与功能影响 |
| :--- | :--- | :--- |
| `HasForest` | `bool` | **是否有森林**：非水、非山、非火山、非冻土地形中，若森林噪声超过阈值则设为 `true`。 |
| `ForestDensity` | `int` | **森林密度 (0~100)**：反映森林的茂密程度，在生成时根据噪声强度缩放写入，用于未来木材砍伐产出计算。 |
| `HasMineralVein` | `bool` | **是否有矿脉**：由矿石噪声与圈层距离共同决定，`true` 时表明该格蕴藏矿产。 |
| `MineralType` | `string` | **矿脉类型**：包括 `"STONE"` (石矿，近圈)、`"IRON"` (铁矿，中圈)、`"CRYSTAL"` (水晶矿，远圈)。空值表示无矿。 |
| `HasHerbs` | `bool` | **是否有草药**：沼泽与草原专属的稀有草药。不可与矿脉在同格重叠，作为药剂调配原材料。 |

### 2.3 建筑数据：`BuildingData`

| 字段名 | 类型 | 作用与功能影响 |
| :--- | :--- | :--- |
| `HasBuilding` | `bool` | **是否有建筑**：标记当前格子是否被任何建筑占据。 |
| `BuildingType` | `string` | **建筑类型 ID**：如大本营 `"BASE_CAMP"`、中立城邦 `"CITY_STATE"`、遗迹 ID 池或奇观 ID 池。空值表示无建筑。 |
| `IsWorldGenerated` | `bool` | **是否为世界生成**：`true` 表示是地图初始化时生成的遗迹、奇观或城邦（不可拆除）；`false` 表示是玩家在游戏中后期自行建造的。 |
| `BuildingLevel` | `int` | **建筑等级**：初始化默认为 `1`，供游戏内升级机制使用。 |
| `IsBuildingBlocked` | `bool` | **是否被怪物阻挡/失效**：与第四层怪物刷新产生联动。当该格有存活怪物时，此字段为 `true`，导致玩家建筑功能失效、无法使用或停止产出。 |

### 2.4 迷雾与怪物数据：`MonsterFogData`

| 字段名 | 类型 | 作用与功能影响 |
| :--- | :--- | :--- |
| `IsDangerZone` | `bool` | **是否为危险格**：用于视觉外框标记，圈层距离较大且怪物生成密度高的格子标记为危险区。 |
| `DangerLevel` | `int` | **危险等级 (1~5)**：按圈层距离向外递增，1代表最低危险，5代表极度危险，直接挂钩怪物等级或未来战斗难度偏置。 |
| `MonsterType` | `string` | **怪物类型 ID**：按圈层距离划分：近圈为 `"SLIME"`、中圈为 `"GOBLIN"`、远圈为 `"ORC"`、极远圈为 `"DRAGON"`。空值代表无怪。 |
| `HasMonster` | `bool` | **是否存活怪物**：`true` 表示当前有怪物实体盘踞，会联动冻结本格的建筑（使 `BuildingData.IsBuildingBlocked = true`）。 |
| `IsExplored` | `bool` | **是否已探索（无雾）**：`true` 代表战争迷雾已开，视野可见；`false` 代表被黑雾笼罩。初始时仅大本营周边 5 格内可见。 |

## 3. 生成常量的具体作用

### 3.1 第一层（地形与气候）关键常量

* `ALTITUDE_SCALE` (`0.04f`) / `HUMIDITY_SCALE` (`0.035f`) / `TEMPERATURE_SCALE` (`0.025f`) / `RIVER_SCALE` (`0.015f`): **噪声缩放比例**。调整噪声图的频次，数值越大噪声起伏越剧烈、越破碎，数值越小越平缓。
* `ALTITUDE_WEIGHT` (`0.7f`) / `RIVER_WEIGHT` (`0.3f`): **高度与河流的融合权重**。决定生成最终高度时，主高度图和河流侵蚀图所占的比例，使河流能够在地貌上冲刷出下陷的峡谷。
* `SAFE_ZONE_RADIUS` (`10f`) / `TRANSITION_ZONE_RADIUS` (`25f`) / `DANGER_ZONE_RADIUS` (`50f`): **安全/过渡/危险区边界**。决定逐格地形计算时的 `dangerBias`，并间接影响怪物危险等级分档。
* `WATER_THRESHOLD` (`0.18f`): **水域阈值**。最终高度低于此值的全部格归入海洋或湖泊。
* `MOUNTAIN_THRESHOLD` (`0.60f`): **山地阈值**。最终高度高于此值的全部格归入山脉。
* `SWAMP_HUMIDITY_MIN` (`0.65f`) / `SWAMP_TEMP_MAX` (`0.45f`): **沼泽气候界限**。高湿度且低温阴凉的平地转化为泥泞的沼泽。
* `EXTREME_RING_MIN` (`70f`): **极地临界圈层**。超出 70 格外的区域开启火山与冻原判定。
* `VOLCANO_TEMP_MIN` (`0.75f`): **火山极热阈值**。极远圈层中温度超过 0.75 的格变为岩浆火山。
* `TUNDRA_TEMP_MAX` (`0.25f`): **冻原极寒阈值**。极远圈层中温度低于 0.25 的格变为终年积雪的冻土。
* `RUINS_RING_MIN` (`40f`) / `RUINS_CHANCE` (`0.08f`): **第一层遗迹标记参数**。在第一层评估地形时，40格外有8%的概率初步产生遗迹地形。
* `PROTECTION_RADIUS` (`5`): **大本营绝对安全半径**。强制中心 `5 * 5` 区块内全是 `PLAINS`，无山地、无深水，确保玩家出生点平坦且可通行。
* `CITY_STATE_COUNT` (`3`): **城邦放置总数**。地图上必须且仅生成 3 个中立城邦。
* `MIN_DIST_FROM_CENTER` (`60f`): **城邦离家最小距离**。城邦离大本营的切比雪夫距离必须严格大于 60 格，避免干扰玩家初期发育。
* `MIN_DIST_BETWEEN` (`40f`): **城邦间距限制**。城邦两两之间的切比雪夫距离必须大于 40 格，使其均匀散布在远方。

### 3.2 第二层（资源）关键常量

* `FOREST_NOISE_SCALE` (`0.06f`) / `FOREST_THRESHOLD` (`0.55f`): **森林生成参数**。噪声值超过 0.55 的格长出森林。
* `FADE_RADIUS` (`12`) / `FADE_MULTIPLIER` (`0.6f`): **大本营减密机制**。在中心 12 格范围内，森林生成阈值上调（即乘上 1/0.6f ≈ 1.66），使大本营附近空旷，便于前期建筑规划。
* `MINE_NOISE_SCALE` (`0.08f`) / `BASE_THRESHOLD` (`0.60f`): **矿脉生成参数**。噪声超过动态计算的阈值时生成矿脉。
* `DISTANCE_FACTOR` (`0.25f`): **矿脉随距离增多机制**。阈值公式为 `BASE_THRESHOLD - (ringDistance/MAP_SIZE) * DISTANCE_FACTOR`，离中心越远，阈值越低，矿产分布越密集。
* `STONE_ZONE_MAX` (`20`) / `IRON_ZONE_MAX` (`45`): **矿物圈层界限**。控制低级、中级和高级矿脉的严格生成区隔，20格以内只有石矿，20~45为铁矿，45格外为稀有水晶矿。

### 3.3 第三层（建筑）关键常量

* `RUINS_MIN` (`5`) / `RUINS_MAX` (`8`): **世界遗迹数量区间**。地图上随机散布 5~8 个供探索和开箱的遗迹建筑。
* `WONDERS_MIN` (`2`) / `WONDERS_MAX` (`4`): **远古奇观数量区间**。随机生成 2~4 个不可重复的宏伟奇观建筑。
* `WONDER_RING_MIN` (`50`): **奇观出生地圈层**。奇观极度神秘，只能在离大本营 50 格以外的偏远荒野生成。
* `MIN_WONDER_DIST` (`20`): **奇观间距**。奇观两两之间必须相距至少 20 格，避免聚堆。
* `RUINS_IDS` / `WONDER_IDS`: **预设建筑 ID 池**。提供彩蛋或特定名称，比如极客奇观 `"WONDER_GIL_LOCK"`、`"WONDER_INFINITE_LOOP"` 等。

### 3.4 第四层（战争迷雾与极客怪物）关键常量

* `SAFE_ZONE_EXPLORE_RADIUS` (`10`): **安全区开雾半径**。与地图中心大本营切比雪夫距离小于或等于 10 的所有网格在初始化开图时自动开雾解锁（`IsExplored = true`）。
* `MONSTER_NOISE_SCALE` (`0.10f`): **怪物分布噪声频率**。频率越大，怪物的聚集成群形态越密集或越破碎；此处严格使用说明书规定的 `0.10f` 频次。
* `THRESHOLD_NEAR` (`0.75f`): **近圈刷怪阈值**。在近圈（`10 < ringDistance <= 25`）的陆地上，若 Perlin 噪声值大于 `0.75f` 则触发刷怪，对应 DangerLevel = 1 (SLIME)。
* `THRESHOLD_MID` (`0.60f`): **中圈刷怪阈值**。在中圈（`25 < ringDistance <= 50`）的陆地上，若 Perlin 噪声值大于 `0.60f` 则触发刷怪，对应 DangerLevel = 2 或 3 (BUG_KNIGHT / NULL_GHOST)。
* `THRESHOLD_FAR` (`0.45f`): **外圈刷怪阈值**。在外圈（`ringDistance > 50`）的陆地上，若 Perlin 噪声值大于 `0.45f` 则触发刷怪，对应 DangerLevel = 3、4 或 5 (NULL_GHOST / DEADLOCK_GOLEM / MEMORY_LEAK_TITAN)。
* `MONSTER_SLIME` (`"SLIME"`) / `MONSTER_BUG_KNIGHT` (`"BUG_KNIGHT"`) / `MONSTER_NULL_GHOST` (`"NULL_GHOST"`) / `MONSTER_DEADLOCK_GOLEM` (`"DEADLOCK_GOLEM"`) / `MONSTER_MEMORY_LEAK_TITAN` (`"MEMORY_LEAK_TITAN"`): **五类极客风格怪物 ID**。对应不同的 DangerLevel 危险档次，并在运行时与建筑受侵占阻挡机制关联。

## 4. 运行时局部辅助变量的作用

* `ringDistance` (`float`): **当前格切比雪夫距离**。计算公式为 `Math.Max(Math.Abs(x - CENTER), Math.Abs(y - CENTER))`。核心控制变量，几乎所有层的资源类型分档、生成几率、地形转化都依赖该值。
* `dangerBias` (`float`): **危险度偏置偏好**。由 `TerrainEvaluator.CalculateDangerBias` 计算：根据 `ringDistance` 与三个安全区常量的关系，产生 `0.0` (安全) 到 `1.0` (极度危险) 之间的偏置值，用于累加高度和气候参数，从而使地图越向边缘生成的地形越发贫瘠与荒凉。
* `rawAltitude` / `finalAltitude`: **高度噪声变量**。`rawAltitude` 为通过 Simplex 噪声函数计算得到的值；`finalAltitude` 是融合了河流数据和危险偏置后的终极高度值，用以评估陆地、海洋或山脉。
* `humidity` / `temperature`: **温湿度变量**。由各自对应的噪声函数生成，并受圈层偏置影响（如外圈极端温度拉高/拉低），共同在地形评估树中做出关键判定。

## 5. 地图渲染与视口裁剪配置：`MapRenderer`

| 变量名 / 属性名 | 类型 | 作用与功能影响 |
| :--- | :--- | :--- |
| `_terrainTilemap` | `Tilemap` | **地形层 Tilemap 引用**：绘制基础地形（平原、水体、山地、冰川等）。 |
| `_resourceTilemap` | `Tilemap` | **资源层 Tilemap 引用**：绘制森林、矿脉（石、铁、水晶）、稀有草药。 |
| `_buildingTilemap` | `Tilemap` | **建筑层 Tilemap 引用**：绘制大本营、中立城邦、世界遗迹及远古奇观。 |
| `_monsterFogTilemap` | `Tilemap` | **迷雾与怪物层 Tilemap 引用**：绘制全黑迷雾瓦片或对应怪物的红色警戒色块。 |
| `_terrainTiles` | `TerrainTileMapping[]` | **地形瓦片映射表**：可配置 `TerrainType` 枚举与 `TileBase` 瓦片资源的配对映射。 |
| `_buildingTiles` | `BuildingTileMapping[]` | **建筑瓦片映射表**：统一管理大本营、城邦、遗迹及奇观等所有建筑 ID 与 `TileBase` 的配对映射（SSOT）。 |
| `_enableCulling` | `bool` | **视口裁剪开关**：默认值为 `false`。启用后仅动态增量刷新相机视野 + 15格边缘的瓦片以大幅节流渲染性能。 |
| `_cullingUpdateInterval` | `float` | **裁剪更新间隔（固定 0.2f）**：用于控制相机移动裁剪的节流频次，防止每帧重复计算导致微小毛刺。 |
| `_cullingTimer` | `float` | **裁剪累计计时器**：在 `Update` 中累加 `Time.deltaTime`，当超出 `_cullingUpdateInterval` 时触发裁剪刷新。 |
| `_lastStartX` / `_lastEndX` / `_lastStartY` / `_lastEndY` | `int` | **上一帧可视区边界缓存**：用于执行高精度 $O(\text{Viewport})$ 增量裁剪差集算法，仅对滑入/滑出的差异网格进行重绘与抹除。 |
